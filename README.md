# 🚀 Portafolio Personal

Este repositorio contiene el código fuente de mi portafolio personal interactivo, desarrollado con **React** y **Vite**.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend:** React
- **Build Tool:** Vite
- **UI Framework / Librerías:** Ant Design
- **Control de Versiones:** Git & GitHub
- **Linter:** ESLint

---

## 📁 Estructura del Proyecto

```text
portafolio-personal/
├── public/          # Archivos estáticos
├── src/
│   ├── assets/      # Recursos (imágenes, estilos)
│   ├── components/  # Componentes reutilizables
│   ├── App.jsx      # Componente principal
│   └── main.jsx     # Punto de entrada
├── .gitignore       # Archivos excluidos de Git
├── eslint.config.js # Configuración de ESLint
├── package.json     # Dependencias y scripts
└── README.md        # Documentación del proyecto

# Instrucciones de Instalación y Ejecución Local

# 1. Clonar el repositorio y entrar a la carpeta del proyecto
git clone [https://github.com/hamontilva-max/portafolio-personal.git](https://github.com/hamontilva-max/portafolio-personal.git)
cd portafolio-personal

# 2. Instalar las dependencias del proyecto
npm install

# 3. Levantar el proyecto en entorno de desarrollo local
npm run dev
